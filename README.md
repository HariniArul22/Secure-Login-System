##### **Secure Login System**



###### &#x20;Objective

Develop a secure login system with registration, login, and logout functionality.



###### &#x20;Features

\- User Registration

\- User Login

\- Session Management

\- Logout Feature

\- Input Validation



###### &#x20;Technologies Used

\- HTML

\- JavaScript

\- Local Storage



###### &#x20;Output

Users can register, login, and logout successfully.
